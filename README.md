# 🐍 my-python-journey

Este repositório foi criado para centralizar todos os meus estudos, anotações e desafios práticos desenvolvidos ao longo do curso de **Python 3**, ministrado pelo professor Gustavo Guanabara no canal Curso em Vídeo.

O objetivo principal é consolidar a minha base em lógica de programação, algoritmos e entender os conceitos estruturais da linguagem Python.

---

## 🗂️ Organização do Repositório

O curso é dividido em 3 grandes mundos, e estruturei os desafios da seguinte forma dentro do projeto:

*   **Mundo 1 (Fundamentos):** Primeiros passos com a linguagem, tipos primitivos, operadores aritméticos, manipulação de texto e estruturas condicionais simples (`if/else`).
*   **Mundo 2 (Estruturas de Controle):** Condições alinhadas (`elif`), estruturas de repetição controladas (`for` e `while`).
*   **Mundo 3 (Estruturas Avançadas):** Estruturas de dados compostas (Tuplas, Listas e Dicionários), funções, modularização e tratamento de erros/exceções.

---

## 🚀 Tecnologias e Ferramentas Utilizadas

*   **Python 3.x**
*   **Visual Studio Code** (ou sua IDE de preferência)
*   **Git & GitHub** (para controle de versão)

---

## 🛠️ Como Rodar os Projetos

Caso queira testar qualquer um dos scripts localmente, siga os passos abaixo:

1. Certifique-se de ter o Python instalado na sua máquina (versão 3.x ou superior).
2. Clone este repositório executando o comando no terminal:
```bash
git clone https://github.com
```
3. Navegue pelas pastas até o exercício desejado através do seu terminal.
4. Execute o script com o comando:
```bash
python nome_do_arquivo.py
```
*(Nota: dependendo do seu sistema operacional, pode ser necessário utilizar o comando `python3 nome_do_arquivo.py`)*
